Diagnostics that motivated the design

  • Ceiling false-positive root cause pre-fix -- height-vs-reference-map-density diagnostic that identified the ceiling structure causing the false-positive burst, motivating the cylindrical near-field gate fix (PIPELINE.md §2.3).
  • Self-hit trajectory, time-sync verified -- the platform's own LiDAR self-returns, isolated by true odometry-time matching (not just spatial proximity, which was found to be 74% false positives on its own).
  • CAD target-drone point-cloud template -- reference point cloud used to reason about how many LiDAR points a target drone contributes at typical near-field ranges.
